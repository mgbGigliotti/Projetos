CCP020 - Reprodutor de Músicas

Introdução

O projeto consiste em montar um reprodutor de músicas utilizando Arduino UNO. A ideia é permitir que o usuário escolha uma música através de botões e consiga reproduzir, pausar ou parar a música.

O circuito será desenvolvido inicialmente no Tinkercad, para testar os componentes e o funcionamento do código antes da montagem física.

Objetivo

Desenvolver um reprodutor com pelo menos cinco músicas armazenadas na memória do Arduino, utilizando um display LCD para mostrar as opções disponíveis.

O projeto também contará com quatro botões de controle, um buzzer para tocar as melodias e dois LEDs para indicar se a música está tocando ou pausada.

Materiais utilizados

- Arduino UNO R3
- Protoboard
- Display LCD 16x2
- 4 botões
- 2 LEDs (verde e vermelho)
- Buzzer
- 3 resistores de 220 Ω
- Potenciômetro de 10 kΩ
- Fios de conexão



Etapa 1 - Montagem do circuito

Primeiro, os componentes foram organizados e conectados no Tinkercad.

Os quatro botões foram ligados às entradas A0, A1, A2 e A3 do Arduino. Os LEDs foram conectados aos pinos 9 e 10, e o buzzer ao pino 8.

Também foi feita a ligação do display LCD 16x2, utilizando um potenciômetro para ajustar o contraste da tela.

Após finalizar a montagem, foi utilizado um código simples para verificar se os componentes estavam funcionando.

Durante os testes, foi possível acender os LEDs, emitir sons pelo buzzer, mostrar mensagens no LCD e identificar os botões pressionados.

Próximas etapas

A próxima parte do projeto será desenvolver o menu de músicas e programar as melodias.

Depois disso, serão adicionadas as funções de reproduzir, pausar e parar, além dos testes finais do sistema.
